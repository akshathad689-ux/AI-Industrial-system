# AI Industrial Safety System

An AI-based industrial safety monitoring system using OpenCV and Telegram alerts.

## Features
- Human Detection
- Zone Detection
- Near/Far Distance Detection
- Gas Hazard Monitoring
- Telegram Alerts
- Real-time Monitoring

## Technologies Used
- Python
- OpenCV
- Telegram Bot API

## Future Improvements
- YOLOv8 Human Detection
- Arduino MQ2 Gas Sensor
- Robot Navigation
- Voice Alert System
